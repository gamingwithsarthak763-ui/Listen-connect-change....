# Community Connect | कम्युनिटी कनेक्ट

A Vite + React + TypeScript community relief platform.

## GitHub Pages

This repository is configured for GitHub Pages. Push it to the `main` branch and the included GitHub Actions workflow will build and deploy the site automatically.

After the first successful deployment, open **Settings → Pages** and use the Pages URL shown by GitHub.

## Local development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
